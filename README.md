# لوحة إعلانات المواد

نظام مجاني بالكامل: صفحة عامة لكل مادة، ولوحة محررين بهوية Google متحقَّقة.

## البنية

- **نشرة (أ) القراءة** — تعمل بصلاحيتك، متاحة لأي زائر. تخدم قراءة المحتوى فقط،
  وتستقبل الكتابة من نشرة (ب) عبر مفتاح داخلي لا يظهر في أي متصفح.
- **نشرة (ب) اللوحة** — تعمل بصلاحية الداخل. تقرأ بريده من Google مباشرة، فلا يمكن انتحاله.
- **الموقع** — `web/index.html` على GitHub Pages، رابط واحد لكل مادة عبر `?m=<معرّف>`.

## التركيب (مرة واحدة)

1. أنشئ Google Sheet فارغ، ومجلد Drive للملفات. خذ معرّف كل منهما من الرابط.
2. أنشئ مشروع Apps Script جديداً وارفع فيه ملفات `apps-script/`
   (أو: `npm i -g @google/clasp && clasp login && clasp create --type webapp && clasp push`).
3. في **Project Settings → Script Properties** أضف:

   | المفتاح | القيمة |
   |---|---|
   | `ADMIN_EMAIL` | بريدك (المدير) |
   | `SHEET_ID` | معرّف الشيت |
   | `ROOT_FOLDER_ID` | معرّف مجلد Drive |
   | `WRITE_SECRET` | نص عشوائي طويل تولّده أنت |
   | `GEMINI_KEY` | مفتاح Gemini (اختياري) |
   | `SITE_URL` | `https://Ana541.github.io/madda-board/` |
   | `READ_EXEC_URL` | يُملأ في الخطوة ٥ |

4. شغّل الدالة `setup` مرة واحدة (تنشئ الجداول وتتحقق من الصلاحيات).
5. **Deploy → New deployment → Web app**:
   - **نشرة (أ):** Execute as **Me** · Who has access **Anyone** → انسخ الرابط
     وضعه في `READ_EXEC_URL`، وفي `const API` أعلى `web/index.html`.
   - **نشرة (ب):** Execute as **User accessing** · Who has access **Anyone with a Google account**
     → هذا رابط اللوحة الذي ترسله للمحررين ولنفسك.
6. ارفع `web/` إلى مستودع GitHub Pages باسم `madda-board`.

> عند أي تعديل على الكود، أعد نشر **النشرتين** (Manage deployments → تعديل الإصدار).

## الاستخدام

- **مادة جديدة:** لوحة الإدارة ← «مادة جديدة» ← يخرج رابط الطلاب جاهزاً. لا كود ولا مستودع.
- **دعوة محرر:** تكتب اسمه أنت، فيُوقَّع به كل إدخالاته ولا يستطيع تغييره.
  الرمز يُستهلك مرة واحدة، ويُربط ببريد Google الذي فتحه.
- **الطلاب:** يفتحون الرابط بلا تسجيل دخول، ويرون السجل الكامل لكل تعديل.

## قرارات مقصودة

- **لا حذف فعلي.** كل تعديل نسخة جديدة، والحذف علامة لا محو. السجل عام للجميع.
- **لا تسجيل IP.** بيئة Apps Script لا تمرّر رؤوس الطلب أصلاً؛ والهوية هنا بريد متحقَّق من Google،
  وهو أقوى من عنوان متغيّر. يُسجَّل بدلاً منه نوع المتصفح الذي يرسله العميل.
- **حد الملف ١٠ ميجابايت** — القيد الحقيقي هو الذاكرة أثناء الترميز لا حجم الطلب.
- **الفحص الآلي لا يُعطّل النشر** عند عطل خارجي؛ الأمان الحقيقي في أن كل محرر مدعوّ بالاسم.
